# 使用指南

本文描述当前桌面客户端。尚未开放的能力见[验收状态](STATUS.md)。

## 界面与对话

左侧为主机及按主机归类的 AI 对话历史，中间是终端／文件／AI 终端标签，右侧为可调宽度、可收起的助手面板。界面跟随系统深浅主题，目前主要使用简体中文。

点击主机即连接并打开普通 SSH 终端。右侧直接输入消息即可开始对话，首条消息自动建立后台记录，没有“创建任务”步骤。切换主机时会显示对应的对话；已运行的旧对话仍绑定原主机，不会因切换标签获得其他主机的权限。

消息与操作结果按时间排列，AI 的结果说明跟随对应操作。用户消息可复制、查看发送时间或编辑补发；编辑后会新增一条消息，原记录保留。

未选择主机时可以自由聊天，但 AI 没有远端操作权限。需要让 AI 操作服务器时，请先连接目标主机，再在该主机的对话中描述目标。旧版本对话只保留可兼容的任务、操作与日志记录供查看，请开始新对话。

## 右键菜单与快捷键

主要界面都支持右键菜单，菜单右侧显示当前快捷键：

| 位置 | 菜单内容 |
| --- | --- |
| 终端 | 复制选中、粘贴、全选、引用输出到 AI、清屏（仅本地显示）、新终端 |
| 输入框 | 撤销、重做、剪切、复制、粘贴、全选（密码与验证码输入框不提供复制与剪切） |
| 主机行 | 编辑主机、安全设置、新终端、断开 SSH、移除主机 |
| 对话历史 | 打开对话、查看完整报告、复制对话文本、删除对话（仅已结束的对话） |
| 标签页 | 关闭标签、关闭其他、关闭全部（运行中的 AI 终端会先确认） |
| 消息与卡片 | 复制文本、复制代码、复制命令与输出、查看日志等 |

默认快捷键（macOS 用 `⌘`）：输入框的复制／粘贴／全选等编辑键位由系统处理（`Ctrl+C/V/A`）；终端动作为复制选中 `Ctrl+Shift+C`、粘贴 `Ctrl+Shift+V`、全选 `Ctrl+Shift+A`、引用输出到 AI `Ctrl+Shift+Q`、清屏（仅本地显示）`Ctrl+Shift+K`；全局动作为新终端 `Ctrl+Shift+T`、关闭标签 `Ctrl+W`、新对话 `Ctrl+N`，其余动作默认未设置。终端动作只在终端内生效；全局键位在终端内同样生效，因此 `Ctrl+W`、`Ctrl+N` 等不再传给 shell。`Ctrl+C` 不绑定任何动作，继续用于中断命令或停止 AI。

在“设置 → 快捷键”中可按键录制修改键位：左侧按分组浏览，右侧点击“更改”后按下新组合；Backspace 清除绑定，Esc 取消；同一组合只能绑定一个动作，与编辑或终端保留键位冲突时会提示。支持搜索、快捷键总开关、恢复本组或全部默认。

## 添加和编辑主机

点击“添加主机”，填写名称、服务器地址、端口及账户，再选择认证方式：

| 方式 | 需要准备 |
| --- | --- |
| SSH Agent | 本机可用的 SSH Agent，且已加载相应私钥 |
| 私钥 | 私钥文件路径；加密私钥还需要对应口令 |
| 密码 | 该 SSH 账户的登录密码 |

私钥路径右侧的“选择文件”打开系统文件选择窗口，默认进入用户的 `.ssh` 目录并显示隐藏文件，也可手动填写完整路径。选择只回填路径，点击保存才提交主机配置；取消选择保留原路径。选择 SSH 私钥不会把它作为附件授权给 AI。

跳板机只能选择已有的可直接连接主机，当前支持单跳。主机行右侧常显“⋯”，可进入编辑、安全设置、新终端、断开 SSH 或移除主机。

修改连接参数后，已有终端和对话继续使用旧连接修订。保存后关闭旧终端并重新连接，新的连接才使用修改后的地址、账户或认证方式。

### 测试连接

添加和编辑窗口左下角均有“测试连接”，小窗口中也固定在底部。

- 使用表单当前值，无需先保存；测试网络和 SSH 身份验证，不运行命令、不打开终端。
- 使用独立临时连接，结束后关闭；已有 SSH 会话不受影响。
- 未修改连接目标和认证配置时，编辑页可复用已保存的凭据。改动地址、端口、账户、认证方式、私钥路径或跳板机后，测试不自动复用旧凭据。
- 首次遇到主机或指纹变化时显示指纹；请通过服务器控制台等可信渠道核对。确认仅用于当前测试，不永久保存信任记录。
- 跳板机与目标主机分别核对指纹；确认单次有效、两分钟过期，修改配置后需要重新测试。
- 测试最长约 45 秒，失败会说明认证、私钥读取、网络或超时问题。需要验证码等额外交互时，按提示保存后通过正常连接完成认证。

测试成功不代表已保存主机，也不代表远端具备 Docker、sudo 或应用部署权限。正常连接仍会按已保存的主机信任状态核对身份。

## 模型设置

进入“设置”，在“API Key”页左侧搜索并选择 Pi 供应商，右侧配置：

1. **API Key**：填写该供应商的有效密钥。
2. **Base URL**：已预置默认地址，可独立修改为兼容接口地址。
3. **模型**：选择该供应商提供的模型；自定义兼容服务按界面填写模型标识。
4. 点击“测试连接”，确认配置可用后点击“保存为默认”。模型测试可能产生供应商调用费用。

“保存为默认”决定新对话的初始模型。已有对话通过输入框下方的模型菜单切换；正在进行的请求继续使用原模型，下一次模型请求才启用新选择。该请求产生的操作仍由其绑定的审核配置处理。

供应商 Key 或地址变化后，历史对话不会静默换用新凭据；按提示重新选择模型或重新应用已保存配置。“订阅登录”当前未开放，不能用它登录 ChatGPT、Claude 或其他订阅账户。

### AI 审核设置

Jev 位于独立的“AI 审核”页面。配置可访问 Vercel Gateway 的 Jev Key 后，第二档使用 `typesafe-ai/jev`；未配置时由当前对话模型独立审核，仍会产生相应模型调用。已经配置的 Jev 调用失败时等待人工决定，不自动切换审核供应商。

## 使用 AI 终端

Agent 按需建立专用命令终端，远端通过 Python 3 组件启动真实 PTY 进程。审核通过后显示完整原始命令、远端用户名、主机与目录，以及实际进程输出，不模拟逐字打字。提示符采用标准 Bash 样式，不加载用户自定义 PS1。助手面板展示操作和少量输出，可打开完整 AI 终端查看；调整窗口或面板宽度会同步终端行列数。

AI 命令需要服务器已有 Python 3；组件不可用时暂停并提示，普通人工 SSH 终端不受此依赖限制。

AI 执行时，AI 终端禁止普通输入或粘贴；不会因为开始打字就接管或触发新的 AI 对话。点击“停止”或在终端按 Ctrl+C（未选中文字时），会停止本轮 AI 并向尚在运行的命令发送中断请求。确认命令退出后，终端自动允许人工输入。对话已经结束时直接输入即可，不再需要接管／交还按钮。

| 操作 | 含义 |
| --- | --- |
| 停止 / Ctrl+C | 停止本轮 AI，尝试中断远端命令；不会发起新的模型请求 |
| 发送消息 / 继续 AI | 明确启动下一轮；必要时新建受控命令终端，旧人工终端保留 |
| 中键点击标签 / 关闭按钮 | 关闭点击的标签；关闭后台标签不会切换当前标签，运行中的 AI 终端仍先确认 |
| 断开 SSH | 断开连接；远端进程是否继续运行需要单独核验 |

用户主动停止、Ctrl+C 或关闭正在执行的终端都会记录中断原因；下一轮 AI 能看到这是用户终止的执行，不会将它当作程序自行失败来自动重试。已发出中断请求不等于远端进程已经退出，退出状态未知时仍先核验。应用重启和上下文整理会保留这些记录。

## 需求澄清

AI 调查已有信息后，如果关键需求仍不清楚，会通过内置 Pi 插件显示 1–3 个问题。选择选项或填写自定义答案，再点击“提交并继续”；推荐选项不会自动提交。等待回答时不会继续执行依赖该回答的操作。停止、取消、超时或重启会让旧问题失效，不自动猜测。本次改版后的问答保留在原生会话里，恢复旧问题不会自动重放工具。

## 审核和交互输入

主机“安全设置”可选择审核档位。所有档位都先执行硬禁令与完整低风险白名单检查；第一档对其他操作逐次人工批准，第二档用 AI 独立审核，第三档自动执行其他未被阻止的操作。审核的具体规则见[安全说明](SECURITY.md)。

需要人工批准时，助手侧栏显示审批卡，可展开完整命令与操作。审批只针对当前内容和当前连接状态；操作、授权或终端控制权变化后可能失效。

需要密码、验证码等信息时显示独立输入窗口，说明用途、目标主机、账户和后果。回答直接送到绑定的认证通道，不经过剪贴板；AI 只收到非敏感状态。取消输入或稍后填写不自动等于停止远端进程。

sudo 按命令需要提升权限：免密时直接继续，只有 sudo 实际请求密码时才打开独立输入窗口。支持可静态解析的前台命令列表，例如 `sudo ls -la /root/test; echo '--- content ---'; sudo cat /root/test/test`，也支持换行及 `&&`／`||` 条件执行。含管道、重定向、动态展开或嵌套 Shell 的 sudo 形式目前需要停止 AI 后人工处理。不要把密码放入聊天或使用 `sudo -S` 传入命令输入。

sudo 确实不可用而需要切换 root 时，可停止 AI 并等待命令退出后执行 `su -`，按服务器提示输入 root 密码；它不是自动绕过权限或审核的后备通道。认证失败、审核拒绝或停止后，AI 暂停远端工作，等待你明确继续。

已审核安装操作的普通继续确认，只有能确认不扩大影响范围时才自动回答。未知提示或无法确认接收方的流程会要求停止 AI 后人工处理。

## 文件、输出与验收

文件页当前只读。AI 可以通过经审核的文件工具写入、上传或删除常规文件；结构化文件工具上限为 1 MiB，覆盖和删除会尽力保存恢复副本。目录删除和符号链接不作为普通文件删除处理。

本地资料通过输入框附件入口明确选择后才可供 AI 读取；不会开放任意本地 Shell。普通终端内容不会自动加入对话，可通过引用入口主动提供。

终端右键菜单、工具栏“引用输出”和引用快捷键都会在 AI 草稿的上次光标位置插入 `Terminal` 标签，添加后仍可直接在终端输入。有选区时只引用选中文字；没有选区时引用最后一条命令及其全部输出。运行中的命令保存点击时的快照，Python 等交互程序以整段会话为单位。无法识别命令边界或日志不完整时，需要手动选择内容。

AI 输入框中粘贴超过 10 行或 1,000 个字符的内容，会在原位置折叠为“粘贴文本”标签；短粘贴和手动输入保持普通文字。点击标签预览内容：终端资料只读，粘贴资料可编辑保存。标签可以与文字混排，支持多个引用、复制、剪切、删除、撤销和重做。Enter 发送、Shift+Enter 换行；只有终端标签时默认请求分析输出。

折叠不会调用模型。发送时按所选模型、会话上下文和回复预留量检查容量，原文能容纳就完整发送；只有超限资料才独立分段总结。处理中的标签显示“正在压缩”，已发送的压缩标签可在总结与原文间切换。准备期间可取消，失败或取消保留草稿；重复发送使用同一请求标识避免重复消息。发送后的标签仍可预览，编辑消息会发送新记录。引用只是资料，不会扩大 AI 对主机的操作权限。

AI 回答支持 Markdown 标题、列表、表格、引用和代码块。代码块复制不会执行代码；图片不会自动加载，网页链接由系统浏览器打开。

远端工作完成后，查看验收卡中的验证证据、访问方式、变更与恢复说明，确认结果后再验收。出现未知执行结果或缺少成功操作证据时，不应仅凭 AI 文字认定工作完成。

## 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 请先配置模型 | 到设置填写 API Key、选择模型并保存 |
| SSH 身份验证未通过 | 检查账户拼写、认证方式、私钥和口令；先用测试连接定位 |
| SSH Agent 尚未就绪 | 启动并加载本机 Agent，或改用私钥文件 |
| 主机指纹改变 | 从可信渠道核对新指纹，确认服务器身份后再继续 |
| 测试成功但连接仍提示核对身份 | 测试确认不永久保存信任；正常连接单独核对 |
| 编辑后旧终端仍使用旧配置 | 关闭旧终端并重新连接 |
| AI 服务不可用或额度不足 | 查看友好错误提示，检查供应商账户、地址及额度 |
| 审批或输入过期 | 等待新请求或重新发起；不要将密码粘到普通 Shell |

新版对话使用本机原生会话文件保存完整模型上下文。重启后需要明确继续；会话文件缺失或损坏时不会用空白上下文替代。输入区下方显示剩余上下文；自动整理期间显示“正在整理上下文”，完成后等待新统计。整理需要一次或多次摘要模型请求，也计入对话请求上限。
