# 修复共享契约与不变量

> 实施基线草案，对应 H01/H02；不是新建一套与现有领域模型并行的万能状态机。具体类型在各修复包中沿既有 core/application/adapters/contracts 依赖方向落地，迁移有版本且不静默猜旧事实。

## 事实、决策与投影分开

1. **目标**：稳定风险目标身份不同于可编辑连接配置ID。连接代次、登录身份、终端代次、目录和策略修订参与授权绑定；非身份配置变化不能清风险，不仅凭IP合并不同目标。
2. **意图**：真实用户输入、引用、模型派生摘要分别带来源。摘要和终端输出只提供资料，不能升级为 explicit 授权。原始约束保留，截断/缺失可见。
3. **派发**：记录可证明未派发、提交到传输、观察到进程启动等事实。失败时不能仅凭退出码/Promise异常猜是否执行；旧数据缺可靠证据继续保守。
4. **结果**：原始进程退出、退出是否观察到、潜在影响、业务观察和目标核验分别表达。查询非零不自动形成变更风险；明确未启动失败不变成远端未知。
5. **审核/调度**：共享影响事实，但敏感读取/外传/变更有各自决策。审批前检查已知不可执行条件，派发前复核动态条件。新终端/新operationId/换身份不能绕未决风险。
6. **操作身份**：同一请求重复派发、未知结果重试、用户明确的新操作和重复观察不同。报告与自然语言总结不能解除真实风险或授予操作权。
7. **控制**：模型暂停、停止指定操作、停止会话、关闭显示/资源、转人工、确认进程退出是不同动作。后台job绑定目标/操作/身份/连接/进程序号；回执不是退出。
8. **权限**：业务工具表达操作级身份意图，后端统一实现。凭据复用不等于操作批准；SFTP身份不因sudo/su改变；prepared不等于已验证root。

## 查询影响证明（A05首子包）

- Core 的 `analyzeQueryImpact` 统一输出业务变更影响、是否具备自动审核候选资格及结构化证明类别。审核分类、防重放和执行侧的 `isEffectFreeQuery` 共用此来源，不再一边认作查询、一边仅因表达形式询问。
- 有界诊断及全部步骤均为已识别查询的字面列表（`;`/`&&`/`||`）可以作为自动放行候选。仅靠程序名、包含一个查询、未知执行上下文、动态展开、无完整拓扑证据的管道或重定向都不构成此证明。
- `effects:none` 不等于访问授权、没有秘密、进程已退出或远端程序身份已核验。敏感/用户保护路径先拒绝；主机/身份/目录/策略/终端代次及持久审计仍在 SafetyGate 中复核。
- 提权查询可以有无变更证明，但不因此新增自动放行权限；旧查询接口兼容保留，不把所有 effect-free 查询直接批准。完整变更、外传和未知原因的统一事实仍属后续子包。

## 查询管道证明（A05后续子包）

- 只有Bash AST明确给出的单一前台字面管道才可申请查询证明。最多6阶段，每个阶段的原始源码跨度与depth=0的完整calls一一对应；不从文本按`|`切分，也不凭扁平命令名列表猜拓扑。
- 首阶段必须满足已有查询/有界诊断语法；后续只接受明确stdin-only参数的grep、head/tail、wc和uniq。文件操作数、递归/模式文件读取、输出文件、执行代码、follow模式均不在候选范围。head/tail显式行数上限1000，grep只接受一个不超过256字符的模式及有限选项。
- 写入、重定向、stderr管道、后台、子Shell、混合列表、动态展开及wrapper额外调用不能继承此证明。旧记录或解析器没有完整证据时保持未知，不补猜。
- 访问策略仍先执行：`.env`/私钥及用户保护文件即使只作为管道源也拒绝。此能力只证明业务变更影响，不保证任意输出没有秘密、执行时长或远端二进制可信；既有输出脱敏、动态授权及持久审计不可绕过。

## 审核具体原因与依据（A07首子包）

- QueryImpact补充有限、固定的审核原因码；区分动态输入、执行上下文、参数语义、重定向、管道拓扑/来源/过滤器、代码入口、身份包装、自定义可执行路径及未覆盖语法。最多4项，文案从固定映射生成，不复述argv、源码、目标或原始解析错误。
- 原因只解释事实，不授予权限；静态禁止规则、三档路由、独立审核和精确人工审批的优先级不因文案改变。已证明可自动放行的查询不新增审核调用，影响未知的命令也不因文案具体就自动放行。
- 独立审核结果与人工决定保留前序规则及静态依据，写入既有operation.reason，避免最终human-approved/human-denied覆盖全部来由。旧记录没有细节时不补猜；展示层保留后端具体依据，不自行重新分类。
- 新增解释经过脱敏、控制字符清理与长度限制。结构化原因码属于core内部事实，本包不改变数据库表或对外授权字段，也不依靠匹配文案决定锁或批准。

## 审批生命周期（A07子包）

- 审批端口的boolean仅代表明确人工批准/拒绝；取消、超时及策略/审核配置失效通过固定ApprovalInterruptedError结果返回，不能全部resolve(false)伪装成人工拒绝。
- Worker先注册具体接收方再发布审批，回执消费前再次检查截止时间与boolean类型；记录一旦消费/失效，重复、外来及迟到回执不能恢复旧批准。发布失败须删除待办、清理计时并失败关闭。
- SafetyGate单次清理审批端口及本地计时/监听；清理异常也必须得到可审计的approval-unavailable，不冒泡为未记录异常或继续派发。取消、过期和授权失效分别记原因，最终失效记录保留先前审核依据。
- 调用方在端口正常或中断返回后都必须退出自己持有的waiting-review状态；finally只清理仍属于当前审批的等待状态，不能覆盖用户已经暂停/接管的状态。
- 审计回调不再重复暂停整轮；统一由既有coordinateDecision按reviewCoordination处理。可修正的授权失效可反馈模型，人工拒绝、审批过期/取消和安全组件失败仍按原规则暂停；不能为避免卡住而把错误当批准。
- 指纹、主机、身份、目录、策略修订、终端代次及派发前复核继续有效。本包只处理人工待审批阶段，不覆盖审核模型在途取消；取消审批不等于停止已派发远端进程，也不解除其他未决变更锁。

## 配置谱系风险域（A01子包）

- 已有`previousHostId`链由Main派生风险域，包含归档配置；缺失祖先保留其ID作为保守锚点，循环/矛盾链拒绝。沿用现有持久谱系，不回填未知物理身份、不改操作的hostId、不迁移凭据接收方。地址/路由变化也不自动切断谱系：共享风险不证明物理目标、登录身份或观察对象相同。
- Worker在接纳任务/连接前绑定风险域；启动先绑定全量配置谱系再恢复未决操作，之后才开放IPC/窗口。绑定批次全验后发布，已有绑定不可替换；排队、前台执行、后台已让出队列但完成信号仍存活的工作都不得被重新归属。跨域成员的等待之后仍复核动态授权，未决锁允许受分类的只读诊断但不放行写入。
- 锁、迟到完成、精确控制和解锁始终归原hostId/operationId；一个风险域可以同时保留多条未决记录。Renderer只用后端投影展示相关阻断项；人工确认处理原操作，不能伪装成成功或自动重放。等待Worker存活复核后、持久化之前，再核对来源、对象及证据。
- 跨配置共享风险只允许展示和显式人工接管来源关联，不自动放宽核验证据的原hostId约束。用户接管仍先持久化、再请求Worker释放单条风险；同步响应丢失不回滚已保存的人工确认。
- **尚未覆盖**：独立新增的重复配置、无谱系旧别名及未知DNS/克隆主机密钥关系。需要后续可信目标关联与冲突策略；不能因为本子包通过就宣称这些绕锁路径已解决，也不能直接按IP或指纹全局合并。

## 数据与安全边界

- 配置及其加密凭据/修订应原子提交，内存在成功后变更。快照的configured状态不解密密钥；实际使用时凭据不可用必须拒绝。
- 思考偏好是后端持久选择，不等于运行时已生效；保存不连接SSH、不恢复Agent、不新开请求预算。迟到观测不能覆盖新选择；真实恢复时应用偏好，不重复同步已经接受的档位。控制尝试仍撤销未派发的准备许可，拒绝无效值也不能让旧许可继续出站；已提交费用不退还。
- 删除涉及数据库、引用、原生会话目录时，采用可恢复阶段/tombstone；不能假装数据库事务覆盖文件系统。
- 发送引用副本与投递准备凭据原子保存；新对话必须在运行请求前显式绑定归属，同一请求再次保存不能切换所有者。失败响应不证明未投递：已绑定副本保留，删除时从数据库同时复核消息、排队输入和其他准备的持有关系。原件/草稿使用独立持有关系，不以无条件扫描代替归属。
- 启动回收先取得应用数据目录的单实例所有权，再打开DB并在接纳IPC/Worker请求前执行。准备来源标记只赋给受保护的新进程，不回填旧数据；未绑定且无持久投递证据才可回收，有矛盾事实继续保留。回收副本不重放消息、不退还已计入的辅助请求额度，也不复活已删除回执。
- 草稿lease由后端绑定受保护进程、真实IPC接收方及主框架代次、对话和主机；跨草稿引用先claim再插入，保留整份草稿历史以覆盖撤销/重做。移除一个可见引用不等于丢弃历史，明确丢弃/取消编辑/删除/Renderer退出才结束持有；发送取消保留草稿。准备阶段释放lease同步撤权，副本原子持久化并交接后不再依赖源草稿存活，但仍复核动态模型/主机/控制绑定。
- claim旧正文不能反向赋予可回收来源。只对新受管原件或已明确释放的消息/准备归属保留回收候选，最后一个消息、队列、准备或草稿持有者释放后才回收；启动恢复与准备回收同事务，来源不明的旧正文继续保留。原生剪贴板须保留引用元数据，失效/损坏引用不得静默降为普通粘贴授权；不把未脱敏粘贴草稿正文写入DB或日志。
- 流式脱敏任意分块等价、有界，并保留ANSI/引号/私钥/溢出的必要安全状态；快照、EOF与落盘使用一致边界。
- 文件读取/写入/删除采用正向类型与限额；条件提交绑定内容/版本/路径身份/元数据和授权。能力不支持必须拒绝，不能默默忽略参数或破坏属性。
- 所有Agent发起的远端变更继续经过SafetyGate；认证走绑定接收方的私密通道；安全/关键持久化失败不得放行。

## 环境、流式与预算

- 环境观测绑定来源/时间/身份/连接/执行环境版本；基础系统、执行上下文、业务能力分层。未知不是false，presence不是ready。
- 基础探测的无Python降级不能伪装成整个执行通道无依赖可用；执行环境与探测PATH/cwd/身份一致。
- 正文增量绑定会话/轮次/消息/序号，与最终持久消息安全接续，处理重复/乱序/中断；不能混入thinking、签名、工具参数或秘密。
- Renderer只投影后端状态，不决定授权、输入目标、停止接收方或清除风险。
- 模型能力上限与单次输出/任务预算分开。重试、独立审核、连接测试与辅助模型请求进入实际出站计数；截断明确，不凭提示词控费。

## 验证与迁移规则

- 每个父项必须有正式目标行为测试；跨模块共享同一事实时增加组合用例。
- 审计反例按修复域迁入Tests，使用明确的预期行为；不得保留“漏洞仍存在则通过”的验收断言。
- 修复前离线基线、每包相关回归、全量工程检查、真实VM/模型验收分别记录，不混称完整覆盖。
- 桌面测试清理只针对观测到的进程身份，裸PID和历史父PID不足以证明归属；出生时间约束父子链，终止前复核，无法核实则失败。Windows使用已绑定原生句柄；POSIX二次检查仍有非原子竞态，不能宣称全平台进程隔离已完成。
- 提交的安全扫描必须针对钩子执行后的实际暂存集合，并核对最终提交范围。非升版钩子只读；升版生成来源只能是当前Git索引（包括部分提交的临时索引），禁止整体git add导入工作区草稿。冲突补丁成批拒绝；混合工作改动保持原样并提示合并，不将索引与工作区写回伪装成同一事务。
- 数据迁移版本化；shadow只比较决策，不双执行远端操作。未决旧记录不因缺字段被升级为成功/无影响。
- 每项在REPAIR_PROGRESS中关联提交、目标测试与未验收边界；存在阻塞或部分实现不标已完成。
