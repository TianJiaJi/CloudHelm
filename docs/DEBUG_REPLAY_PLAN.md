# 提前交付调试回放（G3 前）

> 状态：实施顺序调整，功能尚未交付。先做独立的本地捕获与只读回放，再做原场景复测。正式真机验收仍须独立授权。原 [v5.3 计划](V5_3_REFACTOR_PLAN.md) 的安全边界不变。

## 目标

能回答「用户说了什么、AI 回答了什么、一次工具调用关联哪些操作、每条操作何时批准/派发/退出或被拦截、随后如何核验或接管」。例如同次工具调用先成功执行一个只读身份探针，后续候选被拒，应呈现两条有各自 ID 的操作，而不是用工具调用整体失败覆盖第一次观察。

回放是离线阅读证据，不是重新执行。首版不做模型请求重现、远端命令重放、跨用户分享或云同步。

## A · 设置与本地详细日志

- 在设置增加「调试：详细记录」开关；默认关闭，启用前说明会保存聊天正文和操作信息。首版建议每次启动默认关闭，避免调试结束后忘记停录。关闭后不再捕获；旧文件不会被默默清除，提供打开日志目录和明确的清除入口。
- Main 主进程单写入方，单独保存到应用数据目录 `logs/replay/conversation.log`。使用版本化 JSON Lines（每行一条记录），不向启动控制台打印正文，不改变普通 `runtime.jsonl` 的元数据约束。设置显示实际本地目录、是否正在记录、写入失败状态。
- 全量保存开启后用户和助手**最终可见的聊天正文**，不是只记长度或摘要；不重复写入每个流式增量。不回填开启之前的私人会话。读取现有会话作历史回放是单独显式动作，需标明来源和历史覆盖范围。
- 对规范化的任务、模型请求、工具调用、审批、操作和恢复事件，逐类白名单选取字段。保留时间、单调序号、会话/工具调用/操作 ID、只读分类及理由、派发或未派发、退出码、影响状态、审核与恢复结果。命令和输出只使用已有审核/审计的安全投影；完整性、裁剪和缺失明确标记，不把所有 PTY 字节或原始工具对象直接入盘。
- 绝不接入密码、验证码、私钥、API Key、认证请求回答、原始 IPC、HTTP 请求头或私密通道。不记录模型隐藏推理或环境转储。聊天中误粘贴的已知敏感格式在落盘前脱敏；不能保证识别任意秘密，界面明确提示不要把秘密写进聊天。已知结构引用的凭据或私密正文不自动展开。
- 采用独立目录与最小文件权限，拒绝异常路径/符号链接，单写入队列、有限容量和滚动保留（建议总量不超过 50 MiB，普通运行不积累正文）。上限导致丢失或文件不完整要有标记。关闭、启动及清除的竞态测试覆盖；写入失败只影响调试，不影响业务流程、审批和凭据。

## B · 只读时间线

- 用户在调试设置中打开当前记录，按会话筛选；支持展开聊天正文、按工具调用分组查看操作、定位审批和恢复结果。解析器只接受有界、版本已知的记录，部分末行损坏或滚动缺口须提示。
- 界面只读取后端投影。离线查看不得建立 SSH 连接、发模型请求或触发任何恢复/再执行动作；文件文字按不可信数据显示，不当作提示词或授权。
- 同一工具调用的多个操作分别保留状态。对已观察 `exit 1` 但影响可能仍存的情况，明确区分「已退出」与「副作用未确认」。动作回执和原始操作观察不能相互覆盖。

## C · 复测后再进入 G3

1. 关闭开关：合成会话不产生详细文件，普通诊断继续只有元数据。
2. 开启开关：合成用户/助手正文、工具、审批、两次操作与恢复结果按顺序落盘；私密输入和凭据夹具字面值均不出现。关闭后不再新增；容量、文件错误及脱敏都有回归。
3. 用两个操作的离线夹具复盘「先只读执行成功、后提权候选被拒」，确认一眼能辨别，且无业务执行或模型请求。
4. 真实复测仍由操作者明确授权并使用隔离环境。完成后可用本地日志定位磁盘查询的原命令和定级；不靠摘要猜测，不重放旧命令。

每批先契约测试、再实现，验证通过后本地提交、不推送；历史草稿不并入。已有诊断安全约束继续适用，不能将本需求解释为保存所有内存、私密认证数据或取消保留上限。
