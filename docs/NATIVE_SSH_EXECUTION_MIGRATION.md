# 无远端 Python 基础设施：执行层迁移契约

> 实施记录与各期验证结果见 [评审记录](NATIVE_SSH_DIRECTIVE_REVIEW.md) 与 [交接记录](NATIVE_SSH_HANDOFF.md)；残余事项（H03 真机验收等）以交接记录为准。

> 目标：原生 SSH 是执行基础；远端 Python 仅作为用户明确选择的命令。本文是实施契约，不表示下列阶段已经交付；旧 H03 真机验收仍进行中。
>
> 当前进展（2026-11-20，P0–P3 完成）：远端 Python 基础设施已全部删除——前台命令走零放置 `ssh2.exec`（复合列表、管道、重定向与单字面量解释器均收编入 native-exec，仍按写入审核）、单条字面 sudo／su 走 nonce／窗口标记的 native-pty、后台命令走 setsid 原生后台模块、文件事务走 SFTP 客户端路线与纯 shell 只读降级、sessionId 提权会话派发原生化（sudo 会话凭据仅存 worker 内存并经专用 stdin 注入）。残余不合格形式（wrapper、展开、脱离、复合 sudo、apt 交互不合规等）派发前 fail-closed 阻断。迁移契约四不变量零放宽；各期实施记录见 [NATIVE_SSH_DIRECTIVE_REVIEW.md](NATIVE_SSH_DIRECTIVE_REVIEW.md) 第七至九节。**H03 三链真机验收仍待隔离 VM，未通过**；本地测试通过不代表真实主机验收。

## 不可放宽的不变量

- SafetyGate 是所有 Agent 远端变更的唯一授权入口。通道、渲染后的命令、主机／身份、cwd、策略版本、连接与终端代次在审批前绑定，派发前复核。能力档案只是观察，不是授权。
- 先持久确认操作及审核，再派发。已派发后超时、关闭 SSH channel、断线、缺失 `exit-status` 均不能证明进程退出；结果保持 unknown，写锁不自动解除，不自动重放。
- 不将密码／验证码写入 Shell 命令、普通 stdin、模型上下文或操作日志。无法构建操作绑定的私密接收方时，sudo/su 失败关闭。
- 文件事务的正文、元数据、身份和恢复材料约束不得以 heredoc/rename 的近似实现降级。做不到时明确 `capability_blocked` 且 `effects:none`（仅在证明未派发时）。
- 后台启动和精确停止在独立模块完成前阻断；禁止 `ps | grep | xargs kill` 或依据 SSH channel 关闭推断退出。

## 阶段与验收门槛

1. **原生前台切片**：零放置 `ssh2.exec`，无 Python 主机 `id -u` 可运行。固定环境包装在进入命令正文前完成；注意服务端可能先经账户 Shell `-c` 解析字符串，`env -i` 只能净化子进程。覆盖 NUL、引号、换行、无 `env`／`sh`、cwd、环境注入、分块、stderr、有界输出、缺失退出码与连接撤权。通道选择由后端确定并纳入审批指纹及审计。旧驱动暂不能作为不安全回退；未迁移能力明确阻断。
2. **能力档案、bootstrap 与特权／文件**：新版本化 SQLite 主机能力记录，绑定主机指纹、连接代次、登录身份、观察时间、工具路径及探测来源；失效后重新观察。安装 Python 是经 SafetyGate 审核的普通变更，仅有适用包管理器及确认权限时提供。sudo/su 的私密认证及受控文件事务必须重新证明同等安全语义，不能借人工终端绕开。
3. **后台模块**：独立证明启动、归属、观察、重连与精确停止；PID、PGID、cmdline 不是无竞态凭证，无法独立确认时维持 unknown／写锁。仅在本阶段完成后跑 H03 的后台启动→观察→停止链。
4. **一次性最终切换**：移除 `process.py`、SFTP 放置及 Python 运行前置条件和全部相关测试旧断言；不保留用户可选双通道开关。分阶段开发不等于提前宣称零 Python 完成。

## 验收切片

- 无 Python 的 Alpine/BusyBox 与 CentOS：只读前台真实成功、审计标 native-exec；未知运行时和缺能力明确阻断，不冒充退出 127。
- `python3 -c` 等不透明命令：计划期看到最新能力事实，缺失时不派发；有能力时仍按写入／不确定性路由审核，不因安装 Python 自动授予执行权限。
- 无 SFTP 主机：前台命令不依赖 SFTP；文件能力只在已实现同等安全的替代事务后开放，否则给出明确限制。不可承诺任意主机均能安全写文件。
- H03 分三次核验：前台诊断在阶段 1；配置→校验→服务健康在阶段 2；后台→观察→精确停止在阶段 3。三链全部通过才收口 H03。
