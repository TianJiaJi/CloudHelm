# 验收 V3：事实、目标与影响分开

## 目的

验收不是强迫 AI 填表变绿。后端在收尾时自动生成事实报告；`submit_verification` 是可选补充，不是完成前置条件，不执行命令、不启动另一审核模型、不解除未知结果锁。

## 状态

- **执行**：本轮操作真实成功、失败或结果未知。
- **目标观察**：确定性比较通过/失败/证据不足、模型判断，或尚未比较业务要求。后端会自动记录真实运行结束和捕获输出，不再因模型没提交报告而丢掉运行观察；运行通过不等于业务输出已比较。
- **影响**：只读/已知无影响、影响未独立评估、用户已接管未知风险、仍有未决结果。目标检查通过不代表没有其他影响。
- **登记**：后端自动整理，或已有模型补充。格式修复不应触发远端重放。

## 执行时声明预期（优先，无需再提交报告）

在 `run_remote` 同一调用中传 `outputExpectation: { expectedOutput: "明确的完整预期输出", expectedExitCode: 0 }`。预期在执行前绑定操作，由后端随真实结果比较，不需要额外的 `submit_verification`。后续报告不能修改它制造通过。没有预期时，后端只确认真实运行与输出，不捏造输出内容符合任务要求。

## 可选提交

```json
{
  "version": 3,
  "summary": "本次输出符合预期；影响另列",
  "checks": [{
    "kind": "run-output",
    "operationId": "已有本轮命令ID",
    "expectedOutput": "*\n**\n***\n"
  }]
}
```

`run-output` 由后端比较实际退出码（默认预期 0）与完整捕获输出，CRLF 归一化，其余空白保留。不要求来源命令只读，因为它只证明该次运行的输出。输出被截断、脱敏替换、元数据缺失、退出仅由恢复推断时，不判通过。预期由模型提出，不能把匹配模型预期包装成独立确认用户完整目标。

`model-assessment` 记录复杂业务解释，仍要求合格只读来源，但始终明确标记为模型判断；同主机的无关 stat 不能升级成后端确认配置正确。

写文件的原始 SHA-256、CRLF 归一化文本摘要与完整命令源中的单文件字面 cat 路径由后端捕获，按主机、路径、先后顺序自动匹配读回文本。终端可能转换换行，因此文本比较不冒充远端原始字节的逐位证明。普通 stat、其他文件、跨主机、复合或动态 cat 都不能冒充内容验证。不宣称远端 realpath 已被证明，也不保证观察之后没有并发修改。

## 轮次、恢复与历史

轮次持久化为 `version=1 + roundId + operationIds + closed`，不再用数组偏移。只有后端记录完事实、回答结束后才关闭；缺报告的普通追问和恢复保留原操作集合。新轮次不代表接受旧风险。

报告修订追加到 `verification-reports`，任务投影保留最近 20 份历史。迁移 11 原样归档旧报告，不将旧报告升级为确定性结论。用户显式接管的未知风险始终在后续报告影响栏保留。

## 未启动尝试与后续成功

保留每次尝试的原状态，不把失败记录改成成功。仅当结构化信息确认未派发业务动作（例如 `effects=none + failureKind=unsupported + exit=127`），并有同主机、同身份、同一脚本参数的后续真实成功运行，才把执行汇总标为“后续成功”。不同 cwd 会明确提示，不声称两次环境完全相同。普通非零退出、拒绝审核、未知结果、可能部分生效的失败不能靠后续一个成功命令消除。

字面 Python 脚本调用的目标来自完整命令解析，不能从历史展示 preview 猜测。`ls` 不产生文件内容检查；暂存后 `sudo install` 再运行、只做 `ls` 的流程应显示实际运行观察，而不是谎称读回内容一致。

## 旧报告仅按记录重新整理

已结束且轮次完整的自动报告提供“仅按已有记录重新整理”。这是主进程的数据重投影，不恢复 Agent、不连接 SSH、不运行命令、不调用模型或追加请求预算。旧命令只有在完整 preview 与原始 intentKey 对主机、登录/执行身份和 cwd 的摘要匹配时才可恢复解析目标，不能凭展示文本猜测。操作按持久化轮次 ID 顺序投影，而不是 SQLite 读出顺序。

原报告追加保留，原操作状态、风险接管和锁均不改写；活动任务、未决操作、不完整轮次、提交型报告以及解析期间变化的状态拒绝重整。入口有 5 秒超时和重复点击保护；超过 256 项的轮次明确拒绝，不截断后判为通过。缺少完整输出或预期不会凭空生成业务正确性证明。这个入口用于修正旧汇总，不能拿来重放已经成功的任务。

## 修复上限与安全

V3 语义校验最多允许一次修正（两次拒绝后返回停止指引）。工具 schema 层拒绝仍受全局无进展与请求预算限制；提示词明确不要求为报告不断试错。即使没有合格模型补充，后端仍保存基础报告。

未知远端结果仍使任务暂停，独立写锁和 SafetyGate 不变。任何新增检查仍须原审核与授权。普通聊天、报告登记、运行输出匹配均不构成批准、风险接受或解锁。

## 验证边界

本地单测与模型 HTTP 协议 fixture 可验证状态和工具接入，不等于真实模型/SSH 手动验收。真实三角形任务仍应在用户配置的测试主机、私密凭据通道和明确临时目录中复测；不得从聊天获取密码自动连接。
