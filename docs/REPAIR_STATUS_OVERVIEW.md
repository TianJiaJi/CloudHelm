- **已完成**：按该父项现有验收口径收口，不代表所有平台和安装包均已验收。
- **已实现待验收**：目标实现和局部证据已有，尚有集成、真实环境或阶段收口验收；不能当作已完成。
- **进行中**：存在明确的剩余实现，不只是“再跑一下测试”。
- **待开始**：仍在旧版范围，但尚未正式实施；产品里已有基础能力不等于该包完成。
- **延期转新版**：用户确认暂不按旧版实施，由新版承接；不计旧版分母或剩余，也不计完成。部分移交的父项仍统计其旧版保留范围。
- C02本次按用户选择先安全封口：不能核验完整元数据时拒绝覆盖已有文件，转“已实现待验收”；新建不覆盖、删除副本仅保证正文。不是宣称已支持ACL/xattr保持。当前沿用用户推进口径：**旧版已完成或已实现32项，仍需推进7项（3进行中、4待开始）**；不把28项待验收冒充最终验收完成。
- 严格验收口径：旧版39项中4项已完成、28项待验收、7项仍需推进，即35项尚未最终收口；待验收工作保留在验收范围，不重复列成开发剩余。
- U01–U12为UI细化包，不重复加入42父项；U06延期转新版，其他11包按旧版保留范围跟进。U05/U07仅移交关联状态/控制子项，其独立阅读、输入和草稿功能仍保留。
