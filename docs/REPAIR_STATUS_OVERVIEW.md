- **已完成**：按该父项现有验收口径收口，不代表所有平台和安装包均已验收。
- **已实现待验收**：目标实现和局部证据已有，尚有集成、真实环境或阶段收口验收；不能当作已完成。
- **进行中**：存在明确的剩余实现，不只是“再跑一下测试”。
- **待开始**：仍在旧版范围，但尚未正式实施；产品里已有基础能力不等于该包完成。
- **延期转新版**：用户确认暂不按旧版实施，由新版承接；不计旧版分母或剩余，也不计完成。部分移交的父项仍统计其旧版保留范围。
