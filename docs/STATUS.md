# 实现与验收状态

更新日期：2026-10-06。本文记录本轮桌面终端、sudo、对话与退出流程修复的本机验证。历史三平台 CI 基线与本轮结果分别列出；新提交的云端构建结果应查看其自己的 Checks。

### 原生界面实际检查

macOS arm64 上已打开打包应用，确认主机菜单五项完整浮出、编辑页显示私钥“选择文件”和“测试连接”。已实际打开 macOS 原生私钥文件选择窗口，并取消返回；没有为验证而读取、替换或保存用户真实私钥。

2026-10-06 已在 macOS arm64 修复版应用中连接 Ubuntu 24.04.4 LTS，以非 root SSH 账户通过真实模型执行以下只读命令：

```sh
sudo ls -la /root/test; echo '--- content ---'; sudo cat /root/test/test
```

整条命令退出码为 `0`，目录列表正常，文件内容为 `Hello world`。AI 终端显示完整用户名、主机、目录、原始命令和输出。该服务器此次 sudo 未要求密码，因此只证明这一真实免密读取场景；密码路径证据来自本地替身测试，没有据此声称真实 sudo/PAM 密码输入已验收。没有为本次验证重新写入目标文件。

**Windows 原生文件选择窗口尚未手动实测。** Windows CI 的构建、启动和对话框替身测试不能写成用户手动验收；macOS x64 的完整人工验收也未完成。
