# 实现与验收状态

当前实现面向单主机 AI SSH 客户端。点击主机连接普通 SSH 终端，在右侧直接发送消息；首句自动保存后台执行记录，界面没有“创建任务”流程。旧多主机记录保留供查看。界面采用三栏卡片、石墨灰与低饱和青绿，支持系统深浅主题、可调整助手宽度和 Codex 风格输入框。

## 已接通

- 主机编辑与安全菜单、连接配置修订提示、分主机对话历史、可关闭普通/Agent 终端、只读 SFTP 与报告页。Agent 终端不会自动抢焦点；暂停 AI、停止命令、接管和断开分别处理。
- 主机菜单使用不受侧栏滚动裁切的浮层；私钥路径可通过系统文件选择器选择。添加／编辑主机支持测试未保存的连接配置，使用独立临时 SSH 连接，不保存配置、不打开终端、不影响已连接会话。首次或变化的指纹需核对，确认绑定当前配置、单次使用且两分钟后失效；跳板机和目标主机分别核对。测试最多约 45 秒，需要额外交互认证时提示保存后正常连接。
- Pi SDK 工具循环、结构化计划与验收报告、真实 SSH PTY 命令回显、SFTP 写入/上传/删除恢复副本，以及用户显式选定的本地资料访问。
- 统一审核入口、硬禁令、完整低风险判断、sudo/env/su 等包装递归分析、主机保护路径、审批与执行前的权限复核。第二档无 Jev Key 时使用主模型独立审核；已配置 Jev 故障时转人工，不悄悄降级。
- 操作专属认证通道：sudo askpass、受限 util-linux su、APT 安装确认与 SSH keyboard-interactive。密码不进入普通 PTY、模型、日志或剪贴板。人工接管、断线、超时和操作结束使输入请求失效。
- 双列 Pi 供应商设置、各供应商独立 Key、预置可改地址、显式连接测试、保存默认，独立 Jev 页面。订阅登录明确显示未开放。
- 统一友好错误弹窗，缺少 API Key 时直接引导模型配置；技术详情默认收起，仅展示可识别的脱敏原因。聊天和历史页支持 Markdown 标题、列表、引用、表格与代码块复制；禁用原始 HTML，外链仅允许 HTTP(S)，图片由用户主动打开。
- 对话模型切换在下一次请求生效，当前请求及其审核保持原模型。每次请求保留模型来源。API Key 或地址变化使旧凭据绑定过期；恢复旧对话需用户明确重选模型。
- SQLite 版本化迁移、凭据加密、脱敏分页日志、断线状态更新、重启后未知结果写锁与证据核验。未知结果不会自动重放；已核验的对应操作才解除写锁。
- 单向依赖、循环依赖检查、800 行限制，以及 macOS arm64/x64、Windows x64 CI 构建和启动检查。

## 本机验证

使用 `pnpm check` 执行类型、单元/集成、ESLint、依赖和行数检查。`pnpm test:ui` 使用明确的模拟 SSH/模型后端检查界面流程；`pnpm test:desktop` 和 `pnpm test:desktop:packaged` 在独立用户目录启动真实 Electron，检查 IPC 隔离、SQLite 原生模块、Bash WASM、系统凭据加密与窗口渲染。

临时 localhost SSH 服务验证了主机指纹、真实 PTY、安装确认、人工接管与 SFTP 恢复副本。另有真实 Pi SDK → 本地 OpenAI 流式协议 fixture → WorkerServer → 本地 SSH/SFTP 的多轮测试，覆盖调查、独立审核、文件写入、读回验证、模型切换与验收报告；该测试使用模拟模型响应，不代表真实模型部署质量。

当前标准检查通过 297 项测试，3 项依赖显式 localhost SSH 服务的集成测试默认跳过；新增无需外部服务的真实本地 SSH 握手测试，验证连接测试的指纹确认、密码认证、连接清理和既有连接隔离。UI 回归覆盖菜单点击、私钥选择／取消、测试连接的未保存配置、确认失效和友好结果。真实 Electron 打包启动检查也通过窄 IPC 测试临时本地 SSH 服务，确认不新增主机或终端。macOS 原生私钥选择窗口已实际打开核对；Windows 文件选择窗口尚未手动实测，自动对话框测试使用替身。

macOS arm64 目录包已成功构建和启动。跨平台构建在 GitHub Actions 的原生 runner 执行，最新运行结果与安装包见 [CI 记录](https://github.com/qmgcbcAiden/CloudHelm/actions/workflows/ci.yml)。Windows 安装包由 Windows runner 构建；自动构建与启动检查不代表安装后的人工验收。

## 尚需真实环境验收

- 当前环境无 Docker、真实模型 Key 与目标服务器，尚未完成真实模型自主“容器化 → 部署 → 修复 → 验证”的产品验收。不得把协议 fixture 测试当作这项验收。
- util-linux su 与真实 sudo/PAM 密码验证仍须在 Ubuntu/Debian、Rocky/AlmaLinux 非 root 账户上验收。未知 PAM、密码变更、未识别交互要求人工接管。
- Windows x64、macOS x64 原生模块、SSH Agent、系统凭据与安装包需要对应平台实际验收。本机 macOS 包未签名；发布需要签名与公证配置。
- 订阅登录/OAuth 未开放，不使用第三方应用身份或 Claude.ai 订阅凭据。当前使用 API Key 与兼容地址。
- 文件页首版只读；Agent 文件工具限常规文件及 1 MiB。远端并发符号链接替换和恶意远端环境不具有事务隔离保证。
- 硬禁令属于已知危险形式的尽力识别，无法承诺识别任意编码、间接加载脚本的最终效果。第三档保留此限制。
- 断线恢复依靠本地记录与新的只读调查；不承诺找回已丢失的 SSH 前台进程控制权，也不自动发送 exit、Enter 或 Ctrl+C 来恢复环境。
