## 未证实：所谓「先执行后拒绝」

交接提供摘要，没有两次调用的完整参数、执行/工具回执关联及原始审计证据。静态核对：preflight 的 `unresolved-prior-operation` 直接返回拒绝回执；HostSerialExecutor 的同名拒绝发生于调用下游执行器之前；SafetyGate 使用实际分析结果检查只读续查，并在派发前复核。这只能排除上述分支自身是「执行后再拒绝」，不能证明现场分类正确或两条日志属于同一次尝试。

保留待查。需要操作者提供经脱敏、可按操作/尝试/工具调用 ID 关联的记录，再用离线夹具判断。不同 cwd 可以改变解析后的目标，不能只凭命令摘要相同认定分类必然相同，也不应据此放宽写锁。
