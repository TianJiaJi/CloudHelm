# AI 助手面板界面

当前迭代以 **Trae CN 3.4.9 / VSCode 1.107.1 的 IDE 右侧面板**为参考，修正初版使用国际版 Trae 2.1.2 作为依据的差异。适配到 CloudHelm 现有 renderer，使用自行编写的 React、CSS Modules 与 SVG，不引入 Trae 打包实现、品牌资产、运行服务或遥测。

## 已落地的交互

- 紧凑顶栏：新对话、最近 20 条历史对话、对话详情、模型设置、收起面板。沿用现有菜单的定位、键盘导航、Esc 关闭和焦点恢复。
- 消息区：助手身份行、弱化思考区、紧凑工具活动行；普通成功操作可点击查看完整卡片。
- 思考区：整组「思考过程」和单条「思考」分别展开；流式增量不重置单条展开状态。默认不展示正文；仅显示模型接口实际返回的思考/摘要，不能据此宣称完整内部推理链。
- 思考计时仅用于存在开始时间的流式响应，不捏造已完成响应的持续时间。
- 执行计划移至输入框上方；计数、当前步骤、受阻状态均来自后端 plan。无 plan 时不显示模拟规划。
- 输入框固定在面板底部，支持现有附件、终端引用、模型、思考等级、权限和上下文菜单。原静态 Agent 标记已替换为真正的三档权限切换，底部不再重复显示权限入口。
- 欢迎页建议仅填写草稿，不自动发送。
- 默认跟随消息尾部；读者手动上翻时停止跟随，通过「回到最新」恢复。折叠、宽度调整和长文本不得挤出输入框。
- 深浅主题、键盘焦点与 reduced-motion 样式。
- 核验卡按后端 V3 展示执行、目标观察、影响、登记和报告历史；明确区分“后续成功”“执行观察”和真正输出比较，不把 `ls` 说成内容读回。符合条件时可请求“仅按已有记录重新整理”，重复点击受限，界面不自行重算或授权远端操作。详见[验收 V3](VERIFICATION_V3.md)。

## 未改变的安全边界

- 后端仍是任务、审批、认证和远端状态的权威；界面不自行决定 IPC 投递目标、执行策略或授权；离线报告重整也由主进程校验来源和任务状态。
- 失败、未知结果、拦截、认证反馈和风险接管保留完整卡片，不压缩成成功摘要。
- 审批仍显示具体操作、主机、身份和目录；不增加 Trae 风格的永久自动放行按钮。
- 密码/验证码仍走原有独立交互，不渲染进普通消息或思考内容。
- 停止和恢复仍调用原有接口，不把界面停止动画当成远端进程已终止。

本次原创适配：

- 中性深灰/白色面板与灰阶主按钮，减少原有蓝灰/薄荷色偏色；成功、警告和完全访问仍保留各自状态语义。
- 紧凑顶栏、主机信息、助手身份与工具活动行；普通成功操作仅在真实存在退出码时显示，不补造 0。
- 计划条合并到输入框的同一表面；折叠时在一行显示真实进度及当前步骤，展开列表保持完整标题和键盘操作。
- 按追加要求，删除没有切换功能的静态 Agent 标签，将原底部权限入口移到输入框工具栏左侧；下方只保留上下文用量和真实的待切换模型提示。
- 权限入口复用现有三档（重要操作询问 / AI 审核 / 完全访问）和 `updateConversationReviewMode`，以当前对话/主机的后端状态回显，不修改主机默认档位；完全访问仍以橙色警示，不等于绕过硬禁令。新对话发送前仍继承主机默认档位，未开放新的本地草稿授权状态。
- 工具栏从左到右为「＋附件 / 权限模式 / 模型 / 思考 / 发送」，＋位于模式选择左边；控件按弹性空间排列，长模型名省略但保留完整标题；窄面板权限菜单不丢内容。
- 思考状态变为紧凑披露条，秒数仅来自真实流式开始时间；保留整组/正文两级折叠，增量不能自动打开已收起的思考组。
- 修正权限说明文字，使其与现有三档路由一致；没有改变审核或执行策略。
