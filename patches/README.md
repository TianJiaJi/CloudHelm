# 固定依赖补丁

## iconv-lite 0.7.0

`iconv-lite@0.7.0.patch` 仅修正 DBCS 流式解码的输出缓冲区大小：分配时计入前一分片暂存的字节，而不是只按当前分片分配。

复现：GB18030 编码的 `中文🙂` 在四字节字符的最后一个字节之前分片；原版在只收到最后一字节时仅分配两个 UTF-16 输出字节，丢失低代理项。补丁保留原有编码表、错误处理及接口，不放宽终端输入的无损回读校验。

`Tests/adapters/terminal-codec.test.ts` 保留全部切分点并增加逐字节输入覆盖。补丁由 `pnpm-workspace.yaml` 声明，哈希由锁文件固定；不要手动修改 `node_modules`。
